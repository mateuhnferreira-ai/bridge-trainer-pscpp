⚓ Core Tug Vocabulary

Tug — rebocador.

Towing line — cabo de reboque.

Heaving line — retinida.

Fairlead — guia ou passagem do cabo.

Panama lead — buzina do Panamá / guia reforçada para cabo.

Bitts — cabeços.

Make fast — fazer firme.

Slack away — dar brando.

Let go — largar.

Pull — puxar.

Push — empurrar.
