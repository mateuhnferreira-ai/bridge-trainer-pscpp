🧠 Maritime Vocabulary

Este módulo não organiza o vocabulário simplesmente em ordem alfabética.

As palavras são agrupadas de acordo com situações operacionais, para facilitar a associação entre:

SITUATION → CONCEPT → ENGLISH

⚓ Learning Principle

O objetivo não é pensar:

Português → Tradução → Inglês.

O objetivo é desenvolver:

Operational Situation → Maritime English

🎯 How to Study

📘 LEARN

Veja:

English term

meaning

operational meaning

example

contrast with similar terms.

⚡ RECALL

Veja apenas a palavra inglesa e tente lembrar:

o significado;

o contexto operacional;

uma frase em que ela pode ser utilizada.

🎯 CONTEXT

A palavra aparece dentro de uma situação real.

Exemplo:

"The vessel still has headway although the engine is going astern."

Você deve interpretar o termo pelo contexto.

🎙 SPEAK

Veja a situação e produza a palavra ou expressão diretamente em inglês.

⚠ Words You Must Not Confuse

HEADWAY × AHEAD

HEADWAY

Movimento efetivo do navio para vante.

AHEAD

Direção / condição de propulsão para vante.

Example:

The engine is going astern, but the vessel still has headway.

STERNWAY × ASTERN

STERNWAY

Movimento efetivo do navio para ré.

ASTERN

Direção / condição de propulsão para ré.

HEADING × COURSE

HEADING

Direção para a qual a proa está apontando.

COURSE

Rumo a ser seguido / direção da trajetória, conforme o contexto.

PORT

Pode significar:

bombordo

ou:

porto.

O contexto determina o significado.

Esses contrastes terão importância especial nos futuros modos Recall, Context e Tests.
